Capture to Workshop

It reads the listing: the price, the brand, the description, the product information rows, and every image the page's own data names. That means it reads page markup, which is not a contract and changes without warning -- deliberately, because none of this can be had from a URL. A capture that comes back thin is the signal that something moved, which is why this page tells you what it found before you commit it. It is never refused for reading nothing: a capture with no extraction is exactly the capture this page did before. It submits a form rather than making a background request, because a background request to this host is blocked as mixed content before anything else gets a say. A form is not a way around that, though: a vendor sending upgrade-insecure-requests rewrites the form's destination to https too. Serving this application over TLS is what fixes it. Until then, and for any vendor that blocks the form outright, the paste box on the left is the path that cannot break.
