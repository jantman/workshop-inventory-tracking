The faster way

The Workshop Capture browser extension reads the listing off the vendor's own page. Install it, point it at this application's address once, and a click on its toolbar button lands you here already filled in.

Installing the extension

Download capture-extension.zip from the release matching this application's version, unzip it, and load it unpacked from chrome://extensions. It reads the listing: the price, the brand, the description, the product information rows, and every image the page's own data names. That means it reads page markup, which is not a contract and changes without warning -- deliberately, because none of this can be had from a URL. A capture that comes back thin is the signal that something moved, which is why this page tells you what it found before you commit it. It is never refused for reading nothing: a capture with no extraction is exactly the capture this page did before. The extension can only reach this application over https, and says so where you enter the address. For any vendor it cannot read, the paste box on the left is the path that cannot break.
