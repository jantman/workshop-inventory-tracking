How this works
  1. Capture the order when you place it. Every line becomes an outstanding purchase, so the reorder list knows what is on the way.
  2. When the box arrives, scan each bag's 2D label. It carries the sales order number and the DigiKey part number, which is exactly enough to find the line it belongs to.
  3. What is still outstanding when the box is empty is what DigiKey did not ship.
